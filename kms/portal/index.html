🍄 AAStar Community Node

Buy an NXP FRDM-IMX93 board and run your own KMS / DVT node to join the Mycelium threshold network. No CLI / compiling / Git required.

⚠️ Scaffold build — boards ship with NXP's customized Linux (incl. OP-TEE), no reflash needed; just run one installer for our components. One-click gasless registration is being wired up.

Three steps

① Get a board
Buy an NXP FRDM-IMX93 (ships with OP-TEE Linux), or ask AAStar for a pre-flashed board (mailed).
② Install the node
Connect to network → run one installer (pick a role below) → KMS/DVT installs automatically. No Linux reflash.
③ Configure in browser
Open the board's IP:8088 → fill a few fields → keys generated inside TEE on first boot → join the threshold network.

① Pick a node role

Same set of components; the 4 roles only differ in which services install + the signing method. After you pick one, the commands below auto-append PROFILE.

② Install with one command

Once the board is online, SSH in and run (NXP factory Linux already includes OP-TEE, no reflash):

curl -fsSL https://raw.githubusercontent.com/AAStarCommunity/AirAccount/main/kms/deploy/aastar-node-installer.sh | sudo PROFILE=combined-independent bash

After install: roles with KMS start a config wizard on :8088; DVT on :8080, KMS on :3000. To preview what it does first, add DRY_RUN=1 to only print the plan without changes.

Pre-flashed board (easiest) ★★★ Zero ops

Don't want to touch the command line? Ask AAStar for a pre-flashed board (installed & mailed). Power on → connect → open http://<board-IP>:8088 in a browser and run the wizard.

Full-disk image self-flash ⏳ Pending CI

A .wic full-disk image (drag-drop flash with balenaEtcher) is pending Yocto CI. For now just use the installer above — the factory Linux is identical for everyone, no full reflash needed.

What the config wizard asks

ItemDescription
Setup TokenA one-time token printed on the board's serial/logs (proves you can access the board)
Your domain (rpId)⚠️ Must be your own domain (passkey identity is independent); cannot use aastar.io
Operator addressFor on-chain registration; no ETH needed, AAStar can gasless-sponsor
NetworkTestnet Sepolia (try first) / Mainnet

The wizard does: all private keys are generated on the board at first boot, never displayed; you only fill config locally (no private keys). Protection by role: KMS keys and combined-tee's DVT = TEE-sealed, never leave the TEE; dvt-only / combined-independent's DVT = local EIP-2335 encrypted keystore (generated on board, password via tmpfs, not TEE-sealed).
